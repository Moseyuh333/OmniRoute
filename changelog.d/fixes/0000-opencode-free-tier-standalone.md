- **fix(opencode):** OpenCode Free (`opencode`) and OpenCode Zen free models now answer when OmniRoute is used standalone, without the OpenCode CLI in the loop. Two legs of the upstream client contract were missing: the `tools` list is a fingerprint rather than a non-empty check — the lowercase quartet `bash`/`glob`/`grep`/`read` must be declared, while a lone `_noop` placeholder, a single client tool or the capitalised `Bash` spelling are all answered `403 FreeTierError` — and the `x-opencode-session` value is decoded, so an id that only matched the shape (the previous `12 arbitrary hex` render) is now re-minted in the client's own descending layout, staying stable per conversation so prompt caching still hits. The caller's own tools are kept as they are; the quartet is added beside them, and `opencode-go` plus paid models are untouched.
